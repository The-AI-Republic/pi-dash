- ID prefix: SPC-
- Editions: oss, cloud; web only (no desktop behavior observed; the app is served as a web build only)
- Status of this file: draft for human sign-off (H-signoff-3 via NEWFRONT-10)

- Negative rows (032, 033, 039) record load-bearing absences the new app must preserve.
- New home: route subtree `/spaces/*` in `apps/web_new`, public (no workspace session),
  lazy so visitors never load the workspace shell; web build only (not desktop).
