- Editions: oss, cloud; web only (no desktop behavior observed; the app is served as a web build only)
- Status of this file: draft for human sign-off (H-signoff-3 via NEWFRONT-10)
- Method: read of the old sources listed in the checklist below plus service-layer probes for API paths.
  The old app was not run against a seeded stack in this pass (no local backend here);
  every row must still pass the oracle run (NEWFRONT-97) against the live old app
  before implementation starts. The cloud `ee-overlay` tree is not in this checkout;
  no edition branching was found anywhere under `apps/space` (behavior varies only

  identically except where the instance config is the varying factor.
  Descriptions are paraphrased; no old strings, code, or styles are reused.
- Negative rows (032, 033, 039) record load-bearing absences the new app must preserve.
- New home: route subtree `/spaces/*` in `apps/web_new`, public (no workspace session),
  lazy so visitors never load the workspace shell; web build only (not desktop).
