# Feature inventory: Runners, runs, approvals, runner chat, AI dev machines

Area: Runners, runs, approvals, runner chat, AI dev machines (Phase 2). ID prefix `RUN-`.
Editions: oss, cloud, desktop. The whole area is available in any build where the runner backend
(`/api/runners/…`) is present — there is no client edition/feature flag on the list, pod, run,
approval, dev-machine or runner-detail screens; access is role-gated only. The desktop build adds a
local-execution subsystem (the agent-runtime overlay and a local chat transport) that runs the agent
on the user's own machine; those capabilities are marked `desktop`.

Source behavior learned by reading the old frontend (routes, components, services listed in the
coverage checklist below). The old app was not run in this session; the oracle run (NEWFRONT-34)
verifies each row against the live app later, in both editions where they differ. Written from the
observed behavior; no old code, UI strings, class names, or assets copied.
