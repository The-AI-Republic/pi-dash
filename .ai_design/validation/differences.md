# Differences between the old and new systems

Every deliberate difference between the old Pi Dash (Django + old frontends)
and the new Pi Dash (Rust API + new frontend): one row per difference.
Kinds: old bug fixed, redesign, tier 3, new feature.

| ID      | Area                                                              | Old behaviour                                                                                                                                                                                                                                                                                                                              | New behaviour                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Kind          | Issue / PR                      |

| DIFF-2  | schedulers: recurrence builder                                    | No hour repeat unit: an `FREQ=HOURLY` rule opens in the raw RRULE textarea (`apps/web/core/components/project/scheduler-bindings/rrule-builder.ts` returns null for HOURLY/MINUTELY/SECONDLY).                                                                                                                                             | Hour repeat unit (None, Hour, Day, Week, Month, Year) serialising to `FREQ=HOURLY[;INTERVAL=N]` with the same Ends choices, a dtstart-anchored helper, and a 1–23 interval check.
