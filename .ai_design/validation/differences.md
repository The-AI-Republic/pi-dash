# Differences between the old and new systems

Every deliberate difference between the old Pi Dash (Django + old frontends)
and the new Pi Dash (Rust API + new frontend): one row per difference.
Kinds: old bug fixed, redesign, tier 3, new feature.

| ID     | Area                                                              | Old behaviour                                                                                                                                                                                                                                                                                                                              | New behaviour                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | Kind          | Issue / PR                      |

| DIFF-1 | schedulers: definition color field                                | The color field offers only the 16 preset swatches; there is no custom-color picker.                                                                                                                                                                                                                                                       | The color field offers the same 16 presets plus a "…" (More) overflow that opens the native custom-color picker; a custom color shows on the overflow button.                                                                                                                                                                                                                                                                                                                                                                                                                                                           | new feature   | NEWPIDASH-2                     |
| DIFF-2 | schedulers: recurrence builder                                    | No hour repeat unit: an `FREQ=HOURLY` rule opens in the raw RRULE textarea (`apps/web/core/components/project/scheduler-bindings/rrule-builder.ts` returns null for HOURLY/MINUTELY/SECONDLY).                                                                                                                                             | Hour repeat unit (None, Hour, Day, Week, Month, Year) serialising to `FREQ=HOURLY[;INTERVAL=N]` with the same Ends choices, a dtstart-anchored helper, and a 1–23 interval check. Hourly rules with `BYHOUR`/`BYMINUTE`/`BYDAY` still open raw.                                                                                                                                                                                                                                                                                                                                                                         | new feature   | NEWPIDASH-6                     |
| DIFF-3 | schedulers: edit-save dtstart round trip in the DST repeated hour | The edit modal re-parses the datetime-local wall time on every save (`new Date(local).toISOString()`), so an install whose stored dtstart falls in the second occurrence of a DST fall-back repeated hour is saved back one hour earlier even when Starts at was untouched; every edit-save also truncates a stored dtstart to the minute. | An untouched Starts at input saves the stored instant back unchanged (including any seconds a CLI or API install stored, which the old modal truncated to the minute); an edited wall time inside a repeated hour keeps the occurrence whose UTC offset matches the stored instant. The API contract (dtstart as a UTC ISO string) is unchanged.                                                                                                                                                                                                                                                                        | old bug fixed | NEWPIDASH-22                    |

The malformed (non-UUID) uid 500 on both twins is unchanged (tier 3).                                                                                                                                                                                                                                                                                                                                                                                                | old bug fixed | NEWPIDASH-21 (PB-1044, PB-1055) |
