# Task-oracle files excluded from the Rust HTTP matrix (PIDASHCONV-821).

# The rust-api-contract-rust workflow boots no Celery worker or beat (same as
# the existing Django HTTP workflows: a running worker would consume .delay()
# side effects that HTTP suites do not expect). These files publish jobs in
# Celery wire format and wait for a worker to consume them, so they cannot
# run in that workflow — on either backend — and are passed as --ignore.
# The Django-first run uses the same selection, so oracle validity holds for
# exactly what runs against Rust. This weakens nothing: every file below has
# the same CI coverage it had before this workflow existed.
#
